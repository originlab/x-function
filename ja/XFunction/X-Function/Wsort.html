概要

選択した列を基準にワークシートを並べ替えます。

追加の情報

XファンクションはAuto GetNダイアログとして設計されていません。

コマンドラインでの使用法

1. wsort descending:=1; 
2. wsort descending:=1 bycol:=2 c1:=1 c2:=3; 
3. wsort bycol:=1 irng:=(2[5]:3[8],5[5]:6[8]);
4. wsort bycol:=1 irng:=(1:2,4:end);

Xファンクションの実行オプション

スクリプトからXファンクションにアクセスする場合、追加のオプションスイッチについてのページを参照してください。

並べ替えの基準として使用する列データを指定します。1つの列を基準にワークシートを並べ替える場合に使用します。

入力

int

降順または昇順での並べ替えを指定します。0=昇順、1=降順、2=カテゴリ昇順、3=カテゴリ降順

数値接尾辞で並べ替え sortnumeric

入力

int

0

数値接尾辞を基準に並べ替えるかどうかを指定します。

ネストソート列 nestcols

入力

vector

<optional>

並べ替え基準として使用する列のインデックスです。複数の列を基準にワークシートを並べ替える場合に使用します。

Note:: nestcols を使用する場合
  • order 変数も同時に使用する必要があり、order のサイズは nestcols と一致させる必要があります（下記のSample1を参照）。
  • bycol, descending, sortnumeric などの変数は使用できません。
並べ替え順序 order

入力

vector

<optional>

並べ替え順序のインデックス:

  • 0 降順
  • 1 昇順
  • 4 大文字と小文字を区別
  • 8 数値接尾辞（数値接尾辞を基準に並べ替え）
  • 32 カテゴリ降順
  • 33 カテゴリ昇順
Note:
  • サイズは ネストソート列 と一致させる必要があります。
  • order変数はビットの組み合わせによるオプションです。たとえば、1（昇順）と8（数値接尾辞）を同時に使用する場合は、9（1 & 8）に設定できます（下記のSample2を参照）。

並べ替え範囲 irng

入力

range

<optional>

並べ替える範囲を指定します。範囲は非連続でもかまいません。有効な値が指定されている場合、c1、c2、r1、r2は無視されます。

説明

この関数は、列インデックスとして指定したbycol を基準にワークシートを並べ替えるために使用します。また、nestcols で複数の列を指定してネストソートを行い、各列について降順または昇順を設定することもできます。並べ替え対象の範囲は、開始行、終了行、開始列、終了列、または範囲変数 irng を使用して指定できます。また、数値接尾辞を基準に列を並べ替えることもできます。

/*
この例では、wsort Xファンクションを使用してネストソートを実行します。データは、まずheight列が降順になるように並べ替えられます。同じheightを持つ行が複数ある場合、それらの行はweight列を基準に昇順で並べ替えられます。
1.Originのブックにサンプルデータをインポート
2.wsort Xファンクションを使用してデータを並べ替え
*/
//新しいワークブックを作成
newbook result:=bkname$;	
//ファイルをインポート
path$ = system.path.program$ + "Samples\Statistics\";
fname$ = path$ + "body.dat";
impasc;

dataset sbc = {4, 5}; //第1、第2の並べ替え基準列を選択
dataset sodr= {0, 1}; //並べ替え順序を指定: col(4)--降順、col(5)--昇順
wsort nestcols:=sbc order:=sodr; //ネストソートを実行
