Menu Information

Worksheet: Create Mirror Columns from Sili

Brief Information

Collect columns from similar sheets to create mirrors

Command Line Usage

1. colmirror irng:=[Book1]Sheet1!Col(1) orng:=[Book1]Sheet1!Col(2);

2. colmirror irng:=col(A) orng:=col(B) scope:=2 match:=1 unit:=1;

3. colmirror irng:=[Book1]Sheet1!Col(2) orng:=[Book2]Sheet1!Col(2) xcol:=1 bkrow:=1

Description

Origin 2026b introduces Mirror Column, which references a source column. This X-Function "colmirror" is used to batch-create mirror columns from multiple sheets that match certain conditions, such as column label rows and plot designation, and collect them into one worksheet.
