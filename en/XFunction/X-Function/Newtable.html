Menu Information

File: New: Worksheet: New Data Table

Brief Information

Create a new worksheet or data table by selecting a table type and other settings

Additional Information

Minimum Origin Version Required: 2026b

Command Line Usage

1. newtable type:=free xy:=XY* cols:=10;

2. newtable type:=x names:="Event;Group" xt:=1 xname:=ID;

3. newtable type:=one names:="Event;Group" xt:=1;

4. newtable names:="Event;Group" xname:=ID;

5. newtable type:=con;

6. newtable type:=suv names:="Event;Group" xt:=1 etime:=Months;

Set Column Designatioins xy

Input

string

XY
 Specifies the column designations for all data columns. For example, if you enter XY, the plot designations of the columns will be set to the repeating pattern of "XYXYXY". In this string, each character corresponds to the designation of one column, as shown below:

'X' - X
'Y' - Y
'Z' - Z
'E' - Y Error
'L' - Label
'M' - X Error
'N' - Disregard
