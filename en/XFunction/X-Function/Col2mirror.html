Menu Information

Worksheet: Convert to Mirror Columns

Brief Information

Convert source referencing column(s) to mirror column(s)

Command Line Usage

1. col2mirror scv:=0 colcpy:=1;

2. col2mirror colcpy:=1 label:=1 -u;

3. col2mirror scope:=1;

X-Function Execution Options

Please refer to the page for additional option switches when accessing the x-function from script

  • note:To Notes Window {2}

Description

Origin 2026b introduces Mirror Column, which references a source column. For linking columns created in older versions, whether by column formula (simple reference, no calculation involved) or the Copy Column to dialog, you can use this X-Function "col2mirror" to scan the specified scope and convert these linking columns to mirror columns.
